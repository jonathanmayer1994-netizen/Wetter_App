# Best Weather ☀️🌧️

Eine moderne Wetter-App für das iPhone.

## Geplante Features
- 📍 Aktueller Standort & globale Ortssuche
- 🌡️ Aktuelle Wetterbedingungen & "Gefühlt wie"-Temperatur
- ⏱️ 24-Stunden-Stundenvorhersage
- 📅 7-Tage-Wettertrend
- 💨 Detailwerte: Wind, Luftfeuchtigkeit, UV-Index, Luftdruck & Sichtweite
- 🌅 Sonnenaufgang & Sonnenuntergang
- 🎨 Dynamisches, immersives iOS-Design mit Wetter-Animationen
